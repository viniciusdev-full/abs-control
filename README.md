# abs-control
site desenvolvido para monitorar o uso de absorvente, de um edifício contendo 4 andares sendo térreo, 1,2 e 3 andar. O site na tela de index apresenta as opções do usuário escolher seu andar e redireciona para pagina do andar que o usuário estiver para que possa fazer a retirada do absorvente. Histórico de uso de cada andar aparece na tela do ADM
